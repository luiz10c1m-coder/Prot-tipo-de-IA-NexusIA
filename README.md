# Prot-tipo-de-IA-NexusIA
Protótipo de IA Bancária Integrada (Figma): Desenvolvimento da NexusIA, uma inteligência artificial projetada para transformar a gestão financeira do usuário. A ferramenta auxilia na organização do orçamento, esclarece dúvidas sobre boletos — incluindo a definição de prioridades de pagamento — e realiza a análise detalhada dos gastos mensais.
